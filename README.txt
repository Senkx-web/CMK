ОПИСАНИЕ:
Адаптивный одностраничный сайт, посвященный мотоциклам. 
Проект реализован на базе дизайн-макета из Figma.

СТРУКТУРА РЕПОЗИТОРИЯ:
- /СМК main        : Основная версия проекта (исходный код).
- /CMK no_server   : Версия для локального просмотра без веб-сервера.
- Link_figma.txt   : Ссылка на макет в Figma.

ТЕХНОЛОГИИ:
- HTML5 / CSS3 (Адаптивная верстка)
- JavaScript (Интерактив)

ИНСТРУКЦИЯ ПО ЗАПУСКУ:

1. Для полноценной работы откройте папку "СМК main" через локальный сервер (например, VS Code Live Server).
2. Для быстрого теста без сервера откройте файл index.html в папке "CMK no_server".
3. Для просмотра можете перейти по ссылке:https://senkx-web.github.io/CMK/
